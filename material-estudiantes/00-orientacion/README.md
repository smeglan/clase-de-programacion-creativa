# 0. Orientación del curso

## ¿Qué vamos a construir?

Un portafolio web público con una página personal, proyectos pequeños de aprendizaje y un proyecto integrador, que finalmente acabara en una serie de examenes para medir nuestro conocimiento.

## Stack del curso

- TypeScript para escribir JavaScript con tipos;
- React para construir interfaces con componentes;
- Vite para crear, ejecutar y construir el proyecto;
- CSS nativo para los estilos iniciales;
- Git y GitHub para guardar versiones;
- Vercel para publicar el resultado.

## Carpeta de trabajo

Usaremos un único proyecto llamado `portafolio-programacion`. Dentro de él habrá una sección para cada ejercicio y proyecto.

## Regla de oro

No entregues código que no puedas explicar. Puedes usar documentación, ejemplos y asistentes de IA, pero la responsabilidad de probar y comprender el resultado es tuya.
