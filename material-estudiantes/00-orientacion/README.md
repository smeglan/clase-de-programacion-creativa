## ¿Qué vamos a construir?

Un [portafolio](../glosario.md#portafolio) web público con una página personal, proyectos pequeños de aprendizaje y un [proyecto integrador](../glosario.md#proyecto-integrador). El curso también incluye evaluaciones para revisar lo aprendido.

## Stack del curso

- [TypeScript](../glosario.md#typescript) para escribir [JavaScript](../glosario.md#javascript) con tipos;
- [React](../glosario.md#react) para construir interfaces con componentes;
- Vite para crear, ejecutar y construir el proyecto;
- CSS nativo para los estilos iniciales;
- Git y [GitHub](../glosario.md#github) para guardar versiones;
- [Vercel](../glosario.md#vercel) para publicar el resultado.

El curso tiene dos etapas: primero practicas la lógica con archivos sueltos que ejecutas con Node; después usas Vite para construir y publicar el proyecto web. npm acompaña ambos momentos: permite ejecutar herramientas como `tsx` y administrar las dependencias del proyecto.

## Carpeta de trabajo

Usaremos un único proyecto llamado `portafolio-programacion`. Dentro de él habrá una sección para cada ejercicio y proyecto.

## Regla de oro

No entregues [código](../glosario.md#codigo) que no puedas explicar. Puedes usar [documentación](../glosario.md#documentacion), ejemplos y asistentes de IA, pero la responsabilidad de probar y comprender el resultado es tuya.
