# Material para estudiantes

Bienvenido. Este repositorio contiene todo lo necesario para trabajar en el curso: instalación, programación, React, Git, publicación, vibecoding y retos.

## Empieza aquí: recorrido único

Sigue este orden. No necesitas elegir una ruta: el curso empieza por las bases y avanza hasta una aplicación publicada. Si algún tema te cuesta, vuelve al taller correspondiente; si terminas antes, usa las extensiones opcionales de algoritmia.

1. [Orientación del curso](00-orientacion/README.md)
2. [Herramientas: escribir archivos y ejecutar programas](01-herramientas/README.md) — incluye la [guía del editor VS Code](01-herramientas/editor-vscode.md)
3. [Tu primer programa: hola mundo y `console.log`](02-programacion-base/README.md#tu-primer-programa-hola-mundo-y-qu%C3%A9-es-consolelog) — antes de empezar cualquier guía
4. [Guías de JavaScript: lógica antes de los tipos](02-programacion-base/README.md#gu%C3%ADas-de-javascript-l%C3%B3gica-antes-de-los-tipos) — `if`, `for`, `while` y listas
5. [Fundamentos de TypeScript y lógica](02-programacion-base/README.md)
6. [Taller de retos de fundamentos](02-programacion-base/taller-fundamentos.md)
7. [Guías de algoritmos: Fibonacci y ordenamientos](02-programacion-base/guia-fibonacci.md)
8. [Guía de POO: clases y abstracción](02-programacion-base/guia-poo.md)
9. [Modelado de datos, estructuras y React](03-react-typescript/README.md)
10. [Taller de modelado y React: Fila creativa](03-react-typescript/taller-modelado-react.md)
11. [Git y GitHub](04-git-github/README.md)
12. [Publicación en Vercel](05-publicacion/README.md)
13. [Vibecoding responsable](06-vibecoding/README.md)
14. [Algoritmia aplicada — profundización opcional](07-algoritmia/README.md)

Todos terminaremos con:

- un portafolio web;
- una calculadora o conversor;
- un catálogo o tarjeta;
- una tiendita;
- un proyecto integrador;
- una URL pública para compartir el trabajo.

La guía de POO y la sección de algoritmia no son un requisito ni una segunda ruta: son profundizaciones para cuando ya domines los fundamentos. La guía de POO, además, sirve de puente entre los módulos 02 y 03: introduce la abstracción y las clases justo antes de modelar datos con `type` e `interface` en React.
