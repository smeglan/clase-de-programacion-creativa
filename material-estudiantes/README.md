# Material para estudiantes

Bienvenido. Este repositorio contiene todo lo necesario para trabajar en el curso: instalación, programación, React, Git, publicación, vibecoding y retos.

## Empieza aquí: recorrido único

Sigue este orden para el recorrido principal hasta publicar una aplicación. Primero estudiarás POO; después crearás una página con HTML y CSS directamente en el navegador y la llevarás a React con Vite. La sección de algoritmia es una profundización opcional.

3. [Tu primer programa: hola mundo y `console.log`](02-programacion-base/README.md#tu-primer-programa-hola-mundo-y-qu%C3%A9-es-consolelog) — antes de empezar cualquier guía

## Profundiza cuando quieras

- [Guías de algoritmos: Fibonacci y ordenamientos](02-programacion-base/guia-fibonacci.md)
- [Algoritmia aplicada](07-algoritmia/README.md)

Todos terminaremos con:

- un portafolio web;
- una calculadora o conversor;
- un catálogo o tarjeta;
- una tiendita;
- un proyecto integrador;
- una URL pública para compartir el trabajo.

POO es parte del recorrido obligatorio. La guía independiente de HTML te lleva a construir una página estática; con JavaScript plano añades interacción; después, el módulo 03 muestra cómo organizar la interfaz en un proyecto Vite con React. Las guías extensas de Fibonacci y ordenamientos, junto con la sección de algoritmia, sirven para profundizar.
