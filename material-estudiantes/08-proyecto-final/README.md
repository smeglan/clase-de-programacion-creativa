# 8. Proyecto final

**Estás aquí:** [Inicio](../README.md) › **8. Proyecto final**

En este módulo vas a diseñar, construir y publicar una aplicación web pequeña que resuelva una necesidad concreta. El proyecto integra los temas del curso y añade el consumo de una API preparada por el docente.

Sigue estas dos guías en orden:

1. [Planear un proyecto y organizar su arquitectura](planeacion-y-arquitectura.md): comprender a quién ayudas, levantar requisitos, definir el alcance y planear una estructura sencilla de carpetas.
2. [Proyecto: una herramienta interactiva conectada a una API](proyecto.md): requisitos, alcance, etapas y definición de terminado.

Consulta también la [guía de vibecoding responsable](../06-vibecoding/README.md) para pedir ayuda a la IA, revisar sus respuestas y comprender todo el código antes de publicarlo.
