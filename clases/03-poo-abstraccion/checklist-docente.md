# Checklist docente - Clase 3

## Antes de la clase

- [ ] Probé los ejemplos TypeScript con `npx tsx`.
- [ ] Preparé la situación de catálogo y una lista de atributos candidatos.
- [ ] Preparé la secuencia variables → objeto con tipo → clase.
- [ ] Tengo lista la alternativa de JavaScript sin anotaciones.
- [ ] Revisé la [Guía 7 de POO para estudiantes](../../material-estudiantes/02-programacion-base/guia-poo.md).

## Durante la clase

- [ ] Cada estudiante justifica los datos elegidos según el propósito.
- [ ] El grupo distingue clase, instancia y objeto.
- [ ] Todos ejecutan dos instancias con datos propios.
- [ ] Todos pueden señalar qué significa `this` en una llamada concreta.
- [ ] Todos prueban una regla con valores válidos e inválidos.
- [ ] Se compara clase con `type` y funciones.
- [ ] Se presentan composición e interfaces sin hacer de herencia el objetivo.
- [ ] Cada estudiante escribe una respuesta de salida sobre la abstracción de su modelo.

## Señales de apoyo

- añade propiedades que no usa el problema;
- no diferencia la definición de los valores creados con `new`;
- cree que `this` significa el nombre de la clase;
- modifica el precio directamente sin comprender qué regla se puede romper;
- intenta modelar cada concepto con una jerarquía de herencia.
