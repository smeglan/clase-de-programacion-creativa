# Checklist docente - Clase 4

## Antes de la clase

- [ ] Preparé `index.html`, `estilos.css` y `app.js` en una carpeta de ejemplo.
- [ ] Comprobé que puedo abrir el HTML en el navegador con doble clic.
- [ ] Probé guardar un cambio y actualizar la página.
- [ ] Preparé una tarjeta de perfil o proyecto como referencia visual.
- [ ] Leí la [práctica de HTML y CSS](../../material-estudiantes/02-programacion-base/guia-html-css.md) y la [guía de JavaScript con HTML](../../material-estudiantes/03-react-typescript/guia-javascript-html.md).
- [ ] Confirmé que no se necesita instalar Vite ni extensiones para el ejercicio.

## Durante la clase

- [ ] Todos identifican qué contenido va en HTML y qué presentación va en CSS.
- [ ] Todos guardaron y abrieron `index.html` localmente.
- [ ] Todos incluyeron títulos, párrafos, listas y al menos un enlace.
- [ ] Todos conectaron una hoja `estilos.css`.
- Todos ejecutaron JavaScript con `defer`, seleccionaron elementos y comprobaron el cambio de texto al hacer clic.
- [ ] Todos hicieron cambios visibles en color, espacio y tipografía.
- [ ] El grupo entiende para qué sirven atributos como `href` y `class`, y distingue estructura, estilo y comportamiento.
- [ ] Mostré etiquetas semánticas y hablé de JSX solo como puente hacia React.
- [ ] Cada estudiante explicó una etiqueta y una regla CSS de su trabajo.

## Señales de apoyo adicional

- abre el archivo equivocado o no encuentra la carpeta;
- no guarda el archivo antes de recargar;
- la ruta del CSS no coincide con el nombre real;
- deja elementos mal anidados o sin cierre;
- el script no encuentra el elemento por un `id` incorrecto o falta `defer`;
- elige todas las etiquetas como si su función dependiera de cómo se ven;
- usa colores con poco contraste o texto demasiado pequeño.

## Señales para proponer una extensión

- puede construir la página sin seguir paso a paso la plantilla;
- escribe CSS propio y puede describir el efecto de cada regla;
- incorpora una imagen con texto alternativo;
- adapta el diseño a una pantalla angosta;
- propone una segunda interacción accesible.
